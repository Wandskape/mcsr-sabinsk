## Термины

- **Турнир** — отдельное вручную созданное событие со своими датами, описанием, обложкой и тремя дивизионами.
- **Дивизион** — уровень участников внутри турнира: «Новички», «Опытные» или «Про».
- **Квалификация** — многопользовательские матчи MCSR Ranked, результаты которых формируют лидерборд дивизиона.
- **Квалификационный матч** — импортированный по `match_id` матч MCSR Ranked.
- **Плей-офф** — отдельная ручная single-elimination сетка дивизиона.
- **Матч плей-офф** — пара участников и введённый администратором итоговый счёт. Он не связан с `match_id` MCSR Ranked.
- **DNF** — участник начал квалификационный матч, но не финишировал либо превысил лимит времени.
- **Пропуск** — зарегистрированный участник отсутствовал в конкретном квалификационном матче.
- **Наблюдатель** — пользователь из ответа Ranked API, не зарегистрированный в выбранном дивизионе. Он игнорируется.
- **Снимок импорта** — сохранённый в PostgreSQL ответ Ranked API и нормализованные результаты конкретной версии импорта.

## Правила изменения документации

- Любое изменение формулы очков, жизненного цикла или модели плей-офф сначала оформляется как решение в `12-decisions.md`.
- Изменения API отражаются одновременно в `05-api-contracts.md` и генерируемой OpenAPI-схеме backend.
- Изменения базы сопровождаются Prisma-миграцией и обновлением `03-data-model.md`.
- Завершённый этап дорожной карты отмечается только после выполнения его критериев готовности.
