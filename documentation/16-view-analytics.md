# Обезличенная статистика просмотров

## 1. Назначение

Статистика показывает интерес к основным публичным возможностям приложения без
создания профиля посетителя и без подсчёта уникальных пользователей.

Собираются три события:

- `TOURNAMENT_VIEW` — открылся турнир или посетитель переключился на него;
- `PARTICIPANT_VIEW` — открыто окно участника;
- `MATCH_VIEW` — открыто окно результата квалификационного матча.

Внутренние GET-запросы лидерборда, списка матчей и других данных просмотрами не
считаются.

## 2. Приватность

- Аналитические cookie не используются.
- Баннер согласия для этой функции не показывается.
- В PostgreSQL не записываются IP, user-agent, visitor ID, fingerprint или
  иные идентификаторы посетителя.
- Посещение администратора с действующей административной сессией не
  учитывается.
- Работа публичной страницы не зависит от доступности аналитического endpoint.

Для ограничения повторов backend создаёт HMAC от IP и user-agent только во
временной памяти процесса. Значение живёт не дольше технического окна и не
записывается в логи либо БД.

## 3. Защита от повторов

Одинаковое событие для одного объекта и одного временного fingerprint
учитывается не чаще одного раза за 30 секунд. Дополнительно действует лимит 120
попыток записи в минуту на один временный fingerprint.

При нескольких экземплярах backend дедупликация действует отдельно в каждом
процессе. Для текущего одиночного production-инстанса этого достаточно. При
горизонтальном масштабировании краткоживущее состояние переносится в Redis.

## 4. Хранение

`AnalyticsEvent` содержит:

- тип события;
- UUID открытого турнира, регистрации либо матча;
- время события.

Сырые события хранятся 180 дней и удаляются фоновой компенсирующей очисткой при
поступлении новых событий. `AnalyticsDailyMetric` хранит суточные суммы по
московской календарной дате без ограничения срока.

Запись сырого события и увеличение дневного счётчика выполняются одной
транзакцией.

## 5. Административный интерфейс

Раздел «Статистика» расположен под журналом аудита и доступен только
администратору. Он показывает:

- просмотры турниров;
- просмотры участников;
- просмотры матчей;
- график по дням.

Периоды: сегодня, 7 дней, 30 дней и всё время. Статистика начинает собираться
только после развёртывания функции; исторические HTTP-логи не используются.

## 6. API

```text
POST /api/v1/analytics/views
GET  /api/v1/admin/analytics?period=TODAY|7_DAYS|30_DAYS|ALL_TIME
```

Публичная POST-команда принимает:

```json
{
  "type": "TOURNAMENT",
  "resourceId": "uuid"
}
```

Допустимые типы: `TOURNAMENT`, `PARTICIPANT`, `MATCH`. Несуществующий или
непубличный объект, повтор в пределах окна, превышение лимита и запрос
администратора возвращают `accepted: false` без увеличения счётчика.
